Vampire Wars: Python Combat Simulator

A fast-paced, command-line dice game built entirely in Python. This project was developed to put core programming fundamentals into practice before beginning my Computer Science degree. It features a dynamic turn-based combat system driven by randomized dice rolls, utilizing custom functions, nested while loops, and conditional logic. The script automatically tracks live health points for both players and resolves the match outcome based on round-by-round damage calculations.
