Interactive Weather Dashboard

A comprehensive data visualization tool built entirely in Microsoft Excel. This project transforms raw meteorological data into an interactive, user-friendly dashboard. It utilizes advanced spreadsheet functions, dynamic charts, and conditional formatting to cleanly organize and display complex weather trends. Developing this dashboard allowed me to practice data cleaning, logical formula construction, and analytical layout design—essential skills for bridging the gap between raw data and actionable technical insights.
